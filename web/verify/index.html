What each check means

Five questions, answered by the chain.

  1. Does anyone hold a key?

    An account with no keys cannot sign anything. Nobody can redeploy it, withdraw from it or add a key later.

  2. Is the code a listed release?

    The fund runs one published copy of the code, fixed by its fingerprint. The fingerprint must match a release published in this project.

  3. Can the code change itself?

    Your browser reads the program and confirms it has no instruction that can deploy new code, add or remove keys, stake, or delete the account.

  4. Where do refunds go?

    To a second keyless account that runs the same code and can only pass tokens on to this one fund.

  5. Do the rules add up?

    The contract reports its own rules: who may propose, which tokens, how big a trade may be, and whose signature a quote needs.
